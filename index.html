初始化 SDK

缺少 XGrids Web SDK

该页面使用其域创新官方 LCC Web SDK 渲染 .lcc2 高斯模型，SDK 需要从开发者平台登录下载。

  1. 打开 developer.xgrids.cn 并注册 / 登录账号
  2. 进入「下载」→「LCC Web SDK」，下载最新版本（当前 v0.6.3）
  3. 将 SDK 文件重命名为 lcc.js，放到目录：
    web/vendor/lcc.js
  4. 刷新本页面，模型即自动加载（左下角有水印属正常，appKey 可联系销售去除）

说明：SDK 是官方专有库（非开源），页面已按官方快速入门 API 预先写好接入代码。
